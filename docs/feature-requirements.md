# TechStyle – Feature Requirements

## 1. Personalisierte Produktempfehlungen

### Ziel
Kunden sollen passende Produkte vorgeschlagen bekommen, um weitere interessante Produkte schneller zu entdecken.

### Software-Anforderungen
- Das System soll auf Produktseiten ähnliche Produkte anzeigen können.
- Empfehlungen sollen zunächst anhand der Produktkategorie oder Tags erstellt werden.
- Das System soll später Kauf- und Browserverhalten berücksichtigen können.
- Empfehlungen sollen automatisch aktualisiert werden.
- Die empfohlenen Produkte sollen direkt auf die jeweilige Produktseite verlinken.
- In einer späteren Ausbaustufe soll AI für personalisierte Empfehlungen eingesetzt werden können.

---

## 2. Social Media Sharing

### Ziel
Kunden sollen Produkte einfach über Social-Media-Plattformen teilen können.

### Software-Anforderungen
- Auf jeder Produktseite sollen Sharing-Buttons angezeigt werden.
- Ein Produkt soll über unterstützte Social-Media-Plattformen geteilt werden können.
- Beim Teilen soll ein Link zur jeweiligen Produktseite verwendet werden.
- Produktname und Produktlink sollen an die Sharing-Funktion übergeben werden.
- Die Sharing-Funktion darf den normalen Kaufprozess nicht beeinträchtigen.

---

## 3. Rabatt- und Gutscheincodes

### Ziel
Marketing soll Rabattaktionen und Gutscheine für Kunden anbieten können.

### Software-Anforderungen
- Im Checkout soll ein Gutscheincode eingegeben werden können.
- Das System soll prüfen, ob ein Gutscheincode gültig ist.
- Ein Gutschein soll einen definierten Rabatt besitzen.
- Gutscheine sollen ein Start- und Ablaufdatum besitzen können.
- Ungültige oder abgelaufene Gutscheine sollen mit einer verständlichen Fehlermeldung abgelehnt werden.
- Der Rabatt soll vor Abschluss der Bestellung sichtbar vom Gesamtbetrag abgezogen werden.

---

## 4. E-Mail-Marketing-Integration

### Ziel
Kunden sollen sich für Marketing-E-Mails anmelden können.

### Software-Anforderungen
- Im Online-Shop soll eine Newsletter-Anmeldung angeboten werden.
- Kunden sollen ihre E-Mail-Adresse für den Newsletter hinterlegen können.
- Die E-Mail-Adresse soll validiert werden.
- Newsletter-Anmeldungen sollen gespeichert werden.
- Eine erfolgreiche Anmeldung soll dem Kunden bestätigt werden.
- Das System soll später automatisierte Kampagnen für neue Produkte, Angebote und Warenkorbabbrüche unterstützen können.

---

## 5. Bewertungssystem mit Kundenrezensionen

### Ziel
Kunden sollen Produkte bewerten und ihre Erfahrungen mit anderen Kunden teilen können.

### Software-Anforderungen
- Auf Produktseiten sollen Bewertungen angezeigt werden.
- Kunden sollen eine Bewertung für ein Produkt abgeben können.
- Eine Bewertung soll beispielsweise zwischen 1 und 5 Sternen liegen.
- Kunden sollen zusätzlich einen Kommentar schreiben können.
- Bewertungen sollen dem jeweiligen Produkt zugeordnet werden.
- Das System soll eine durchschnittliche Produktbewertung berechnen und anzeigen können.
- Bewertungen sollen dauerhaft gespeichert werden.
